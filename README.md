# Microsoft 365 · Service-Desk-Fallstudien

Drei simulierte Supportfälle für Outlook, Exchange Online und Microsoft Teams. Die Fallakten zeigen, wie eine Meldung aufgenommen, eingegrenzt, überprüft und an die zuständige Stelle übergeben wird. Es werden keine realen Tickets oder Tenant-Daten verwendet. Die Abläufe sind als Jira-Service-Management-kompatible Dokumentation angelegt und benötigen keine Jira-Instanz.

| Fall | Eingangsmeldung | Schwerpunkt |
| --- | --- | --- |
| [M365-01](faelle/01-outlook.md) | Outlook zeigt „Getrennt“ | Web-Gegenprobe und Eingrenzung auf den Client |
| [M365-02](faelle/02-freigabe.md) | Senden als Funktionspostfach schlägt fehl | Full Access und Send As prüfen |
| [M365-03](faelle/03-teams.md) | Teams-Mikrofon bleibt stumm | Hardware, Windows und Teams unterscheiden |

## Einen eigenen Fall dokumentieren

Die [Ticketvorlage](TICKETVORLAGE.md) erfasst Auswirkung, erste Prüfschritte, Berechtigungsgrenzen, Gegenprobe und Rückmeldung. Neue Erkenntnisse als konkrete Befunde dokumentieren und Vermutungen als solche kennzeichnen.
